# Print production

## Pipeline
1. Every print file is an HTML page built in JS from `src/data.js` and `src/rules.js` (`print/<name>/<name>.mjs`). `@page { size: Wmm Hmm; margin: 0 }`, one `.page` div per physical page.
2. `print/render.mjs` renders it with Playwright (Chromium) to PDF at the exact size, plus a PNG preview of the first page.
3. Print-shop files go through Ghostscript (`print/cmyk.mjs`): DeviceCMYK, `/prepress`, and a TrimBox/BleedBox for the cut. Chromium only writes RGB.
4. `src/pdfcheck.js` reads the result without dependencies: page sizes, page count, any RGB left (DeviceRGB, CalRGB, ICC with 3 channels, `rg`/`RG` operators), trim and bleed boxes.
5. `scripts/print-all.mjs` does all of it and exits with 1 on any problem. `PRINT.shop` and `PRINT.home` in data.js say which files go where.

Setup on a new PC: `npm install`, `npm run browser`, Ghostscript (Windows installer, not on PATH by default: the script also looks in `C:\Program Files\gs\*\bin`, or set `GS=<full path to gswin64c.exe>`).

## Sizes
- Board: A1 (841 × 594 mm) for 8-10 players around a table, A2 for small tables, A3 for an example. 3 mm bleed on every side.
- Cards: poker 63.5 × 88.9 mm (some shops use 63 × 88). 3 mm bleed. One card per page. Keep text 4 mm inside the cut.
- Many shops want **one recto-verso PDF**: front 1, back 1, front 2, back 2, … Make that the shop file; keep a fronts-only file to proofread on screen.
- Team aid: A4 per team, double-sided (flip on the long edge), in the team colour. Booklet: A5 pages plus an imposed A4 version to fold (double-sided, flip on the short edge).
- Money: home-printed notes on heavy paper (120-160 g), with cut marks. Print as many as the sims' max money in circulation × 1.25 (`material.moneyToPrint` in the balance report). To split it per value, simulate payments with real notes (pay with the fewest notes, take change from the bank) and count the most of each value any team held.

## Readability
- Board text readable at 1.2 m: town names ≥ 9 mm cap height on A1, road prices in a white disc. Print a piece at full size before sending.
- Names must not cross roads or borders: measure it in the real render (Playwright can return each label's bounding box) and fail a script when one does.
- No player text runs off a page: look at the previews every time.

## Colour
- Team colours: test them in simulated colour blindness (protanopia, deuteranopia, tritanopia) with a ΔE threshold, and give every team a shape (circle, triangle, square) next to its name.
- Colours depend on materials: the spray paint or filament you can buy decides the team colours, not the other way round.
- A shop CMYK conversion shifts colours, especially bright blue and orange. A home sticker never matches a printed background: make it a visible label instead of a fake patch.

## Fonts
Bundle OFL fonts as woff2 in `print/fonts/` and load them with `@font-face`, so the print looks the same on every PC. Wait for `document.fonts.ready` before rendering (render.mjs does).

## Pieces
- 3D-printed pieces from OpenSCAD (`.scad` + exported `.stl`), with a print plate script that lays out N per colour within the printer bed (assert when it does not fit). Print in white, spray the colours.
- Count: max per team from the sims + 2 spare. Test print one first (time and fit on the board).
- Dice, sleeves and chips: put them on a material list (`docs/material.md`), generated by a script from data.js and the sims so it never drifts.

## Delivery
- Send the CMYK files with a short note: size, bleed, trim box present, CMYK, double-sided order, cut or not.
- Ask the shop early: bleed, card size, recto-verso in one file, paper weight, lead time.
- After the freeze, anything wrong on printed material gets a home-printed sticker (generate it from data.js too).
